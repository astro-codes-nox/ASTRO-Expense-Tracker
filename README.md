# 💰 ASTRO Expense Tracker

A modern Android Expense Tracker App built with **Kotlin + Jetpack Compose + Room Database**.

---

## ✨ Features

- ➕ Add Transaction
- ✏️ Edit Transaction
- 🗑 Delete Transaction
- 🔍 Search Transactions
- 🎯 Filter Income & Expense
- 💰 Monthly Budget
- 📊 Statistics Dashboard
- 📈 Expense Chart
- 📂 PDF Report Export
- 🌙 Dark Mode
- 💾 Local Database (Room)

---

## 🛠 Tech Stack

- Kotlin
- Jetpack Compose
- Room Database
- Navigation Compose
- Material 3
- Vico Charts
